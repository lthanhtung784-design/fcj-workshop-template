### Week 1 Objectives:

- Get acquainted with members and working environment of First Cloud AI Journey (FCAJ).
- Understand FCAJ's working rules, internal procedures, and communication channels.
- Become familiar with the AWS Cloud ecosystem and major AWS service categories.
- Create and configure an AWS account and understand the AWS Free Tier / AWS Credits program.
- Practice basic AWS services through the $200 credit tasks.
- Explore previous AWS projects and understand possible directions for future team projects.
- Form a working team and establish an initial communication and collaboration process.

### Week 1 Achievements:

- Gained an understanding of FCAJ's internship rules, procedures, and working environment.
- Developed a basic understanding of AWS Cloud and cloud computing concepts.
- Became familiar with the major AWS service categories and their basic use cases:
  - **Compute:** EC2, Lambda → services for running applications and workloads
  - **Storage:** S3, EBS → services for storing data
  - **Database:** RDS → services for managing relational databases
  - **Networking:** VPC → services for building and managing cloud networks
  - **Security:** IAM → services for managing identities and access permissions
  - **AI/ML:** Amazon Bedrock → services for building and using generative AI applications
  - **Monitoring & Management:** CloudWatch, AWS Budgets → services for monitoring resources and managing costs
- Understood how different AWS services can be combined to build a basic Cloud architecture.
- Gained basic hands-on experience with EC2, Amazon Bedrock, Lambda, RDS, and AWS Budgets.
- Learned the fundamentals of AWS Credits and cost management, including resources that may consume credits quickly.
- Gained an overview of previous AWS/Cloud/AI projects and potential directions for future project development.
- Developed initial teamwork and communication skills through collaboration with a five-member team.
