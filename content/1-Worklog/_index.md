This worklog covers my 10 weeks in the First Cloud AI Journey (FCAJ) program from **14/09/2026** to **20/11/2026**.

Each week, I followed the FCAJ modules and AWS documentation, practiced on my AWS account and CLI, and recorded the daily tasks, dates, references, and key takeaways. Across the 10 weeks, the worklog moves from onboarding, basic AWS services, and team setup to IAM, VPC, EC2, S3, RDS, monitoring and security services, backup and disaster recovery, Lambda, CloudFormation/CDK, containers and CI/CD, and cost management.

Weekly overview:

**Week 1:** [Getting familiar with FCAJ, AWS service categories, cost basics, past projects, and forming a 5-member team](1.1-week1/)

**Week 2:** [IAM model, MFA and least privilege, VPC basics, EC2 setup, and IAM roles for EC2](1.2-week2/)

**Week 3:** [Static website hosting on S3, S3 security settings, AWS CLI profiles, CloudWatch alarms, and private RDS](1.3-week3/)

**Week 4:** [Private S3 access via VPC endpoints, VPC Flow Logs, Systems Manager Session Manager, and tag-based access control](1.4-week4/)

**Week 5:** [IAM conditions and policy evaluation, permission boundaries, AWS SSO (IAM Identity Center), KMS, and Secrets Manager](1.5-week5/)

**Week 6:** [CloudTrail, GuardDuty with EventBridge/SNS alerts, Security Hub, AWS WAF, Macie, and Firewall Manager](1.6-week6/)

**Week 7:** [AWS Backup and EBS lifecycle policies, Elastic Disaster Recovery, handling a leaked access key, and Amazon Cognito](1.7-week7/)

**Week 8:** [Lambda automation, CloudFormation and CDK, EC2 Image Builder, and highly available web architectures](1.8-week8/)

**Week 9:** [Docker and Amazon ECS security, CodePipeline CI/CD, SQS and SNS, and X-Ray tracing](1.9-week9/)

**Week 10:** [Savings Plans and Reserved Instances, cost visualization and anomaly detection, Glue and Athena, account security review, and 10-week review](1.10-week10/)
