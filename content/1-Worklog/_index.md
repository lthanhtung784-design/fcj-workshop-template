This worklog documents my learning and hands-on practice over **10 weeks** (from **14/09/2026** to **20/11/2026**) in the First Cloud AI Journey (FCAJ) internship program.

I completed the worklog by following weekly FCAJ modules, AWS official documentation, and hands-on labs in my AWS account and CLI, recording daily tasks, timelines, references, and weekly takeaways. Across the 10 weeks, I progressed from onboarding, AWS fundamentals, and the $200 credit tasks to identity and access management, networking, compute, storage, database, monitoring, security governance, backup and disaster recovery, automation and IaC, containers, CI/CD, and cost optimization.

Weekly contents are structured as follows:

**Week 1:** [FCAJ onboarding, AWS core services, $200 credit tasks, cost basics, and team setup](1.1-week1/)

**Week 2:** [IAM fundamentals, MFA and least privilege, VPC networking basics, EC2 setup, and IAM roles](1.2-week2/)

**Week 3:** [Static website hosting on S3, S3 security settings, AWS CLI profiles, CloudWatch alarms, and private RDS](1.3-week3/)

**Week 4:** [Private S3 access via VPC endpoints, VPC Flow Logs, Systems Manager Session Manager, and tag-based access control](1.4-week4/)

**Week 5:** [Advanced IAM conditions and policy evaluation, permission boundaries, IAM Identity Center (SSO), KMS, and Secrets Manager](1.5-week5/)

**Week 6:** [CloudTrail auditing, GuardDuty threat detection and alerting, Security Hub, AWS WAF, Macie, and Firewall Manager](1.6-week6/)

**Week 7:** [AWS Backup and EBS lifecycle policies, Elastic Disaster Recovery, leaked key incident response, and Amazon Cognito](1.7-week7/)

**Week 8:** [Serverless automation with Lambda, CloudFormation and CDK, EC2 Image Builder, and highly available web architectures](1.8-week8/)

**Week 9:** [Docker and Amazon ECS security practices, CodePipeline CI/CD, SQS and SNS messaging, and X-Ray tracing](1.9-week9/)

**Week 10:** [Savings Plans and Reserved Instances, cost visualization and anomaly detection, Glue/Athena cost queries, account security review, and 10-week consolidation](1.10-week10/)
