5.7 · COST · Estimate and billing

For 300 reports in 30 days, PhishGuard’s planning budget is USD 9.37 before tax and domain renewal. The AWS Pricing Calculator export plus three separately priced items gives USD 9.21 for the same workload. Section 3 reconciles the two estimates. The total in the Cost Explorer extract for 1–23 November 2026 rounds to USD 0.00. Section 4 explains the scope of that account report.

1. Scope and workload

The application runs in US East (N. Virginia), us-east-1, behind a pay-as-you-go CloudFront distribution protected by the PhishGuardEdge web ACL. Its final rule set includes one standard AWS managed rule group and one rate-based rule. The monthly budget excludes the temporary header probe used for the 403 test. There are two observed alarms, covering workflow failures and the Ingest dead-letter queue. Viewing a WAF graph in the console adds no custom metric to this model.

The scenario assumes that the 300 reports include 90 images, 60 incoming SES messages and 90 cases reaching a decision. These categories can overlap. The portal makes 12,000 HTTP API requests. CloudFront serves 20,000 HTTPS requests and 1 GB to viewers. For budgeting, every report makes one model call and one KB query. In practice some cases stop early for lack of evidence. A direct browser POST to S3 bypasses the CloudFront WAF request path.

DynamoDB and S3 Vectors inputs

DynamoDB. The form shows 6,000 writes and 30,000 reads per month with 100% eventual consistency. For individual 1 KB items, each eventually consistent read uses half a read request unit (RRU), giving 15,000 RRUs. The planning budget uses 30,000 RRUs, equivalent to 60,000 such reads. It also budgets 0.05 GB-month of table storage and 0.05 GB-month of PITR. The export confirms the table size. The screenshot and export do not establish whether PITR was included in the Calculator. S3 Vectors. The form shows one index, 1,024 vectors, 1,024 dimensions, 100% overwritten per month, and 300 queries per month. The key is 0.2 KB per vector, with 1 KB of filterable and 5 KB of non-filterable metadata. The index is configured for 1,024 dimensions. Checking the estimate against the account bill

  • Reopen Billing and Cost Management → Cost Explorer with the same dates, Daily → Group by Service → Unblended cost. Include all regions so global services remain visible. Capture the date range, metric and filters. Download CSV is below the chart. Mask account names and identifiers in a public screenshot. Export cost data
  • Make a second view grouped by Charge type. Compare it with Bills → November 2026 → Charges by service / Credits. Record the usage charges, credits or refunds, and tax that actually appear. If the account is shared, use an activated cost allocation tag where available. Mark any unattributed amount as shared. Export again after month-end if a final statement is needed.
  • To investigate Bedrock, open CloudWatch → Metrics → AWS/Bedrock in the calling region and select the model or inference profile. Check Sum for Invocations, InputTokenCount and OutputTokenCount over the same period. Compare timestamps with an incident’s Synthesize logs. The metrics describe usage. Bills and charge types explain the monetary adjustments. Bedrock runtime metrics

5. Controlling costs while preserving evidence

  • WAF accounts for about 75% of the baseline. Keep the probe only while testing and use the existing alarms to monitor failures. Add a paid dashboard when someone has a recurring need for it.
  • Measure AI and OCR at the step that incurs the charge. Separate image and text cases when sampling Extract’s Billed Duration. For Synthesize, measure tokens and the number of cases that reach this step before changing model or context length. Include Guardrails and KB queries when comparing alternatives. Lambda · Bedrock · S3 Vectors
  • Clean up according to retention requirements. Review log retention, older object versions and intake storage after the demo. Preserve the evidence retention period. Recalculate when new measurements of storage volume or OCR duration are available. S3 · KMS
